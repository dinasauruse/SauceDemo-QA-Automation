# SauceDemo-QA-Automation
Web UI test automation project using Katalon Studio for SauceDemo application

## Project Overview

This project focuses on practicing software testing and web UI test automation using Katalon Studio. It covers the QA testing process, including test planning, test scenario design, test case development, test execution, and test reporting.

## Application Under Test

- **Application:** SauceDemo
- **Website:** https://www.saucedemo.com/
- **Testing Type:** Functional Testing, UI Testing, Automation Testing
- **Automation Tool:** Katalon Studio

## Testing Scope

The project covers the following features:

- Login
- Product Listing
- Shopping Cart
- Checkout
- Logout

## Test Documentation

- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Report
- Bug Reports

## Tools & Technologies

- Katalon Studio
- Git & GitHub
- Excel

## Disclaimer

This project is created for learning and portfolio purposes only. It is intended to demonstrate software testing concepts and test automation practices using Katalon Studio. All testing activities are conducted on the publicly available SauceDemo demo application and are not associated with any official SauceDemo testing or development team.
